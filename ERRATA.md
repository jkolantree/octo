# Errata

## v0.3.0-alpha.2 publication date

The immutable `v0.3.0-alpha.2` source metadata records `2026-07-20` as the
software release date. The annotated Git tag and GitHub Release were actually
created on `2026-07-21` UTC. The public GitHub timestamp is authoritative for
the software publication event, so citations should use `2026-07-21`.

This is a metadata correction only. The tagged commit, release assets,
checksums, mathematical statements, and executable behavior are unchanged.
The separately licensed research note retains its own publication date.

The root citation and software-archive metadata on the development branch have
been corrected. The immutable tag has not been rewritten.
