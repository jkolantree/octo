    Local consistency inspection

    Audit Return Desk

    Bring back a structured audit_return.json and the files it declares. The Desk checks strict JSON, version bindings, source and evidence references, fatal-gate projections, execution disclosures, and local SHA-256 matches.

    Consistency is not truth. A consistent result is not proof, citation verification, checker execution, scientific correctness, admissibility, or deployment approval.

    Strict parsing rejects duplicate keys, trailing data, non-object JSON, and UTF-8 input above 8 MiB. Page code does not transmit or intentionally persist this text.

    Loading a JSON file replaces the pasted return in this page. This page code does not upload it.

    The Desk hashes up to 32 readable files locally, at most 64 MiB per file and 256 MiB total, then matches exact filenames and SHA-256 values. Larger or additional declared artifacts remain review-needed. Browser file paths are never collected.

        Read before relying

        A careful packet is not a truth certificate.

        The builder assembles instructions. The Return Desk performs local structural and hash-consistency checks. Neither runs the BSC Python checker, verifies citation meaning, authenticates evidence, executes theorem provers, or decides whether a scientific theory is true.

        Do not upload secrets, identifying records, controlled information, or material you are not allowed to share. Prefer a local approved workflow for sensitive targets.
