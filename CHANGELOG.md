# Changelog

All notable public changes are recorded here. Pre-1.0 interfaces may change incompatibly; migration notes preserve prior artifacts.

## 0.3.0-alpha.1 - 2026-07-20

### Added

- versioned v0.3 manifest schema and compatibility contract;
- conservative CLI decision vocabulary and documented exit codes;
- structured malformed-input behavior;
- source-coverage, prompt-injection, and privacy requirements for LLM-assisted drafts;
- documentation index and unified status model;
- governance, security, conduct, issue-triage, and pull-request policies;
- example catalog and accessible offline start page.
- explicit check-run/check-not-run ledgers in every structured result;
- deterministic wheel, source archive, conformance bundle, SBOM, and checksums;
- resource ceilings for JSON, exact rationals, matrices, atomic records, observations, and defect paths.

### Changed

- public wording now distinguishes supported finite structural checks from arbitrary proof or truth verification;
- evidence maturity is separated from research verdict, deployment, gate state, and CLI decision;
- zero-install tests run cross-platform through `python scripts/run_tests.py`;
- domain-specific arithmetic language is no longer the primary public entry point.

### Known limitations

- no arbitrary theorem proving or empirical truth adjudication;
- local evidence bytes are hash-checked, but their external scientific meaning is not automatically verified;
- no certified interval backend;
- no completed infinite-dimensional arithmetic operator construction;
- pre-1.0 schema stability is not promised.

## 0.2.1 - 2026-07-20

Onboarding and distribution files were added around the v0.2 structural kernel. The release remains archived; several public-contract and versioning issues are corrected in v0.3.0-alpha.1.

## 0.2.0

Added product-valued gates, fatal dependency propagation, atomic-modulus records, exact affine defect composition, and adversarial fixtures.

## 0.1.0

Introduced manifest linting, exact rational complexes, transport defects, square holonomy, finite observation descent, and scoped domain gates.
