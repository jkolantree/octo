## 公式 GPT を使う

公式の [BSC Claim Auditor](https://chatgpt.com/g/g-6a601b1f576881918e659b363ed3063f-bsc-claim-auditor) は、固定 URL と [current status page](../CUSTOM_GPT_STATUS.md) から利用状況を確認できます。preserved [2026-07-22 snapshot](../PUBLICATION_STATUS.json) は historical evidence であり、current-state feed ではありません。通常の利用者には公式サービスを先に案内し、repository package は任意の検証、reproducible deployment、fork、authorized update に使用します。

このリポジトリの GPT パッケージは、公式構成を検査・再現・フォークし、次の更新候補を評価するための公開ソースです。パッケージが存在することだけでは、その候補が公式 GPT に導入済み、特定の Git コミットに結合済み、または Preview 評価済みであることを意味しません。次の状態は必ず分けて扱います。

- 公式サービスが利用可能か
- リポジトリの候補パッケージが生成・検証済みか
- 公式 GPT の保存済み構成が候補パッケージと厳密に結合されているか
- 候補構成が全 Preview 評価に合格したか
- GitHub Release と Pages がどのバージョンを公開しているか

候補が `PENDING` の間は、導入済み・検証済み・リリース済みと表現してはいけません。

## 日本語で監査を依頼する

質問を日本語で書くか、「日本語で回答してください」と指定してください。説明、見出し、修正案、および注意事項は日本語で返せます。一方、次の機械可読要素は翻訳・音写・正規化せず、原文どおりに保持します。

- JSON のキーと列挙値
- Schema、ルール、finding、claim、gate、artifact の識別子
- `proven`、`plausible_but_unresolved`、`pass`、`unrun` などの正規トークン
- パス、ファイル名、コマンド、ハッシュ、バージョン、終了コード
- 監査上重要な引用文

必要なら、正規トークンの直後に日本語の説明を添えます。例: `plausible_but_unresolved`（もっともらしいが未解決）。日本語だけの別トークンに置き換えてはいけません。引用を翻訳する場合は「翻訳」と明示し、判断に重要な原文も残します。ハッシュ計算前のバイト列を翻訳・改行変換・Unicode 正規化してはいけません。

## 監査深度

- `quick`: 主張と決定的な証拠または失敗を短く確認します。
- `standard`: 主張、依存関係、証拠、反証、未解決点を標準的に監査します。
- `adversarial`: 反例、境界条件、情報漏洩、矛盾、欠落仮定を強く攻撃します。
- `formal-mathematical`: 対象、量化、仮定、結論、証明段階、形式ツールの境界を厳密に確認します。

深度を指定しない場合は `standard` です。`adversarial` と `formal-mathematical` では、条件を満たす場合に人間向けの `audit_report.md` と機械可読の `audit_return.json` を分けて生成します。正確なファイルとハッシュを作れない場合、もっともらしい JSON を捏造せず、生成できない理由を説明します。

## 実行に関する表示

言語モデルによる推論、添付ファイルの読み取り、Web 検索、ChatGPT の Data Analysis、BSC Python、外部証明支援系、実験は別々に記録します。

- ファイルを読んだだけなら `file_read_only` であり、計算や検証の実行ではありません。
- BSC Python を実行したと主張できるのは、バージョン、入力、出力が特定された実行記録がある場合だけです。
- Lean、SMT、区間演算、実験の提出済み receipt は、監督された再実行と再生可能な証拠がない限り、証明権限を持ちません。
- 実行されていない計算は提案として記録し、結果を `pass` にしてはいけません。

## プライバシー境界

GitHub Pages の Packet Builder と Audit Return Desk のページコードは、対象資料を送信せずにブラウザ内で準備・整合性確認を行うよう設計されています。ただし、ブラウザ、OS、拡張機能、クリップボード、クラッシュ復旧、ダウンロード済みファイルの挙動はページの管理外です。

資料を Custom GPT に貼り付ける、または添付すると、ChatGPT の適用される設定・規約・データ制御の下で処理されます。これはローカル専用ではありません。秘密情報、個人情報、医療・法務情報、機密情報、輸出管理対象、共有権限のない資料をアップロードしないでください。

## 独立して再現・フォークする

再現手順は、公式サービスの現在状態にかかわらず、透明性、独立検証、研究用フォーク、または権限を持つ保守担当者による更新のための選択肢です。公式 URL の利用可否は、再現手順ではなく current status page で確認します。

1. 厳密な候補パッケージと SHA-256 台帳を検証します。
2. `GPT_INSTRUCTIONS.md` と指定順の Knowledge ファイルを使用します。
3. Apps と Actions を追加せず、宣言された capability を一致させます。
4. 全 Preview ケースを新しい会話で実行し、生の応答と採点記録を保存します。
5. 自動失格が一つでもあれば候補を昇格しません。
6. 公式更新では、保存済みエディタ構成、公開表示、正確な結合、評価結果を別々に確認します。

独立フォークは公式 BSC Claim Auditor ではありません。名称や説明で公式性、検証済み状態、または BSC Python の実行権限を誤認させないでください。
