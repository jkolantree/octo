1. **Public Custom GPT - direct ChatGPT audit:** **UNPUBLISHED** until an authenticated human completes [setup, Preview evaluation, and sharing](../gpt/GPT_SETUP_AND_PUBLISHING.md). ## LLM use

The [LLM Audit Packet](../BSC_AUDIT_LLM_PACKET.md) is a drafting protocol, not an executable verifier. Read its privacy, prompt-injection, and source-coverage rules before attaching material.

The static [Pages module](../pages/README.md) is the accessible front door to that same canonical packet. Its committed protocol copy and checksum metadata are mechanically generated and checked for drift.

The repository also contains a deterministic [Custom GPT setup package](../gpt/README.md). The package is published as repository material, but the Custom GPT itself remains **UNPUBLISHED** until the authenticated human setup and Preview gate are complete. Direct uploads are processed through ChatGPT and do not inherit the Packet Builder's local-only construction boundary. The package includes no GPT Action, hosted checker API, account system, or cloud-storage service.

The next trust-layer priority is the Audit Return Desk for inspecting returned model output and receipts. It is planned, not implemented.
